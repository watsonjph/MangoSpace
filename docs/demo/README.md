# Hubas slide demo

[Download the seven-slide PowerPoint](Hubas-demo-final.pptx).

The English deck uses real packaged NISAR/Sentinel-1 observations and Playwright screenshots, with editable soil/rice charts. Chart values are rounded to six decimal places, beyond the app's displayed precision. Source links are in speaker notes. The last slide has the live app URL and “Measured, not forecast”. Team names are the current Shortcut display names and must be confirmed against event registration before submission.
